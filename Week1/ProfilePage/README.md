# Internship Task: Week 01 — HTML5, Accessibility & Git

## Description
This repository contains the submission for the Week 01 internship task. The goal was to build a personal profile page using pure semantic HTML5 and CSS fundamentals, focusing on code structure, accessibility, and version control standards.

**Note:** While the requirement was limited to a semantic profile page, I have extended the functionality to include **full responsiveness** for mobile, tablet, and desktop devices.

## Topics Covered
* **HTML5 Semantics:** Utilization of tags like `<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, and `<footer>` for better document structure.
* **CSS Fundamentals:** Custom styling, flexbox layouts, and media queries.
* **Accessibility:** Implementation of ARIA labels to support screen readers.
* **Git Basics:** Clean commit history and repository management.

## Deliverable: Semantic Profile Page
A personal portfolio website for **Vishnu Burkhawala** built from scratch using HTML, CSS, and JavaScript.

### Key Features
* **Semantic Architecture:** Built using proper HTML5 landmarks (`<nav>`, `<section>`, `<article>`) to ensure SEO-friendliness and clear code hierarchy.
* **Accessibility Support:** Integrated `aria-label` and `aria-expanded` attributes on interactive elements (like the navigation menu) to enhance screen reader support.
* **Fully Responsive Design:** Custom CSS Media Queries (`mediaqueries.css`) ensure the layout adapts seamlessly to mobile (max-width: 600px), tablet (max-width: 1200px), and desktop screens.
* **Interactive UI:** Includes a functional JavaScript-based hamburger menu for mobile navigation and interactive hover states for buttons.
* **Project Showcase:** Dedicated section using `<article>` tags to display projects like "Clinico," "Linkify," and "ShelfScrap."

### Key Learnings
* Proper use of semantic tags improves document structure and readability.
* Responsive design principles (Media Queries) are essential for modern web accessibility.
* Accessible markup benefits all users, not just those using assistive technology.
* Clean, atomic Git commits facilitate easier collaboration and version tracking.
